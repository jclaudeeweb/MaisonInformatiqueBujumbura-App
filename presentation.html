Gestion Association App

A propos y'ibikorwa vyacu

Gestion Association App ni application yakozwe kugira ifashe amashirahamwe n'abadandaza gucunga neza ibikorwa vyabo biciye kuri telefone canke kuri ordinateur.

Ibikorwa vya Application

  • Gestion ya stock n'ibicuruzwa
  • Kwandika ibicuruzwa vyaguzwe
  • Gukurikirana ventes
  • Gucunga amafaranga yasohotse (Depenses)
  • Gestion y'abanyamuryango
  • Gukurikirana cotisations
  • Gukora rapports z'amafaranga
  • Système ya roles: Vendeur, President na Membre

Ikibazo ikemura

Amashirahamwe menshi akoresha impapuro mu kubika amakuru, bigatera kubura amakuru canke amakosa mu guharura amafaranga. Iyi application ifasha kubika amakuru neza no kubona rapport vuba.

Technologies zakoreshejwe

  • HTML
  • CSS
  • JavaScript
  • LocalStorage
  • PWA (Progressive Web Application)

Ivyo nshaka guteza imbere

  • Gushiramwo database online (Firebase)
  • Gukora Android Application
  • Kunoza umutekano wa login
  • Gukoresha abantu benshi bari ahantu hatandukanye
  • Kunoza design n'ibindi bikorwa
